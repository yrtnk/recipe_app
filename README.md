# 試作レシピ管理（Streamlit Community Cloud 共有版）

社内の担当者数名で試しに触ってもらうための、クラウド共有版です。
ローカル版との違いは、ログインが「ブラウザのタブを閉じるまで有効なセッション記憶」になっている点です
（複数人が同じアプリインスタンスにアクセスするため、ファイルに保存する方式は使えません）。

## ⚠️ 使う前に必ず確認してください

- **Streamlit Community Cloudの無料枠は、リポジトリが「公開（Public）」である必要があります。**
  コード（このapp.py・parser.py・db.pyなど）は誰でも閲覧できる状態になります。
  試作データそのものはリポジトリに含まれません（アップロードされたExcelやDBの中身はGitHubには載りません）が、
  社内の業務ロジックや命名規則が外部に公開されることは踏まえたうえでご利用ください。
- **保存したデータ（recipe.db）は消えることがあります。** 無料枠は再デプロイやスリープからの復帰時に
  ファイルシステムがリセットされることがあり、永続保存は保証されません。**あくまで動作確認・お試し用**とし、
  本番の試作データはこの共有版には入れないでください。
- 無料枠は15分程度アクセスがないとスリープし、次のアクセス時に30〜60秒程度のウォームアップがかかります。

これらの制約に引っかかるようになったら、それが「AWSへの本番移行のタイミング」の目安だと考えてください。

## GitHubへの登録・デプロイ手順

1. GitHubで新しいリポジトリを作成する（例: `recipe-app`）。Publicのままで問題ありません。
2. このフォルダの中身一式（`app.py` / `db.py` / `parser.py` / `requirements.txt` /
   `.gitignore` / `.streamlit/config.toml` / `README.md`、任意で`sample_data/`）を
   そのリポジトリに登録します（GitHub Desktopを使うか、以下のコマンドでも可）。
   ```bash
   git init
   git add .
   git commit -m "initial commit"
   git branch -M main
   git remote add origin https://github.com/【あなたのアカウント】/recipe-app.git
   git push -u origin main
   ```
3. https://share.streamlit.io にアクセスし、GitHubアカウントでログインする。
4. 「New app」→ 先ほどのリポジトリ・ブランチ（main）・メインファイル（`app.py`）を指定する。
5. 「Deploy」を押すと、数分で `https://【何か】.streamlit.app` のようなURLが発行されます。
6. このURLを担当者に共有すれば、ブラウザだけで動作確認できます（各自インストール不要）。
